# NYC-Citi-Bike-Station-Level-Demand-Analysis--Using--Tableau

🚲 Citi Bike Demand & Expansion Intelligence

❓ Where Should Citi Bike Expand Next?

A data-driven dashboard designed to uncover demand patterns, rider behavior, and geographic opportunities to inform strategic expansion decisions for a bike-sharing network.

📌 Project Overview

This project analyzes Citi Bike trip data to answer a key business question:

Where should Citi Bike expand to maximize demand, efficiency, and rider experience?

Using recent trip data, the dashboard provides a structured analytical narrative—moving from high-level demand trends to actionable expansion recommendations.

🎯 Key Objectives

Identify high-demand areas for station expansion

Understand rider behavior (commuters vs leisure users)

Analyze seasonal and time-based trends

Explore trip flow patterns across boroughs

Provide data-backed business recommendations

📊 Dashboard Features

🔹 1. KPI Overview

Total Trips

Average Trip Duration

% of Subscribers

👉 Snapshot of overall system performance

🔹 2. Demand Trends

Trips over time (monthly trend)

👉 Identifies growth patterns and volatility

🔹 3. Seasonality Analysis

Trips by season (Winter, Spring, Summer, Fall)

👉 Reveals peak demand periods and seasonal shifts

🔹 4. User Behavior

Trips by user type (Subscriber vs Casual)

Average trip duration by user type

👉 Highlights:

Subscribers = high-frequency commuters

Casual riders = longer, leisure trips

🔹 5. Time-Based Patterns

Trips by time of day

Heatmap: Time of day vs trip duration

👉 Identifies commuting peaks vs leisure usage windows

🔹 6. Location Analysis

Trips by borough

Top neighborhoods by trip count

👉 Pinpoints high-density demand zones

🔹 7. Station Performance (Key Visual)

Scatter plot:

X-axis → Average Trip Duration

Y-axis → Trip Count

Color → Borough

👉 Used to identify:

Commuter hubs (high trips, short duration)

Leisure zones (low trips, long duration)

Expansion opportunities

🔹 8. Flow Analysis

Origin–Destination matrix (start vs end boroughs)

👉 Reveals:

Core intra-borough demand

Key cross-borough corridors

Network connectivity gaps

🔍 Key Insights

🚴 Commuter demand drives the system

High-frequency, short trips dominate usage

⏱ 5–15 minute trips are the core of the network

Indicates strong utility for daily commuting

🏙 Manhattan is the primary demand hub

Highest density of trips and station activity

🔄 “Destination sink” effect exists

Bikes accumulate in high-demand drop-off areas

🌉 Limited cross-borough connectivity

Especially between outer boroughs like Queens

💡 Strategic Recommendations

📍 Expand in high-demand commuter corridors

(Manhattan & Brooklyn hubs)

🚲 Improve bike availability in peak hours

Focus on morning & afternoon commuting windows

🔁 Optimize fleet rebalancing

Move bikes from destination sinks back to origin hubs

🌐 Strengthen cross-borough connections

Especially underserved areas like Queens

🌳 Target leisure zones for growth

Expand services (e.g., e-bikes) in long-duration areas

🧠 Analytical Approach

The dashboard follows a story-driven structure:

What is happening? → Demand trends

When does it happen? → Seasonality & time patterns

Who is driving it? → User behavior

Where is it happening? → Geographic analysis

Why does it matter? → Station performance & flows

What should we do? → Recommendations
